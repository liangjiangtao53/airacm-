## 目标

验证微信小程序复用学习、考试、错题和学历提升能力，同时保证账号不串号、卡密有效期不被绕过、考试草稿不丢失、提审包不包含公开 UGC，并且不破坏 H5 和 Android App 的原有功能。

## 受影响页面

- `pages/login/index`：微信快捷登录、卡密登录、账号登录和失败回退。
- 登录页内的微信绑定状态：已使用卡密、未使用卡密、账号密码绑定。
- `pages/complete-profile/index`：未使用卡密补全手机号和昵称。
- `pages/index/index`：小程序显示学习、考试、错题和学历提升功能，不显示论坛和下载 App。
- `pages/study/index`：顺序续学、跨 20 题边界、跳题、颜色、答案和图片。
- `pages/exam/index`：单科考试、未答题跳转、草稿同步、恢复和放弃。
- `pages/exam-review/index`：全部题目、100 分制、答案颜色、按需解析。
- `pages/wrong/index`：只显示顺序学习错题和模块筛选，不显示评论。
- `pages/forum/index`：不得注册到 MP-WEIXIN 路由，也不得生成页面目录。
- `pages/upgrade/index`：只显示三所学校和客服提示。

## 受影响接口

- `POST /auth/wechat/login`
- `POST /auth/wechat/bind/key`
- `POST /auth/wechat/bind/password`
- `DELETE /admin/users/:id/wechat-binding`
- `GET /exams/active`
- `PUT /exams/:id/draft`
- `POST /exams/:id/abandon`
- 现有论坛主题、回复、题目评论接口不得出现在 MP-WEIXIN 产物中；H5 和 Android App 保持不变
- 现有学习、考试、错题和回顾接口回归

## 关键端到端流程

1. 微信首次登录 -> 未绑定 -> 已使用卡密绑定 -> 首页 -> 原学习记录存在。
2. 微信首次登录 -> 未使用卡密 -> 补全资料 -> 激活卡密 -> 绑定 -> 首页。
3. 微信首次登录 -> 账号密码绑定 -> 原考试和错题记录存在。
4. 微信再次登录 -> 直接进入首页 -> App 旧会话失效。
5. 开始 M3 考试 -> 作答 -> 切后台/结束进程 -> 重进 -> 恢复题序、答案和当前位置 -> 交卷。
6. 构建 MP-WEIXIN -> 自动扫描产物 -> 发现论坛路由、UGC 接口或评论/回复文案时构建失败。
7. Admin 解除微信绑定 -> 审计日志完整 -> 原学习和卡密数据不变 -> 可重新绑定。

## 后端自动测试

### 微信平台服务

- code2Session 成功、无 openid、错误码、超时、非法 JSON。
- 客户端重新获取 code 后重试成功。
- access token 首次获取、缓存命中、提前刷新、并发只刷新一次、刷新失败。
- 内容安全通过、风险、超时、错误码；日志不包含 AppSecret、code、完整 openid 和原文。

### 绑定会话

- 只保存 token 哈希，不保存明文。
- 五分钟过期、成功消费、重复消费、服务重启后仍有效。
- 失败次数达到限制后锁定。
- 清理每次不超过 100 条且使用过期索引。

### 卡密与账号绑定

- 已使用有效卡密绑定现有用户。
- 未使用有效卡密原子创建用户、钱包、卡密关联和微信绑定。
- 卡密无效、过期、作废、手机号重复、昵称重复全部回滚。
- 同一微信并发绑定两个用户只有一个成功。
- 同一用户并发绑定两个微信只有一个成功。
- 账号密码正确/错误、无密码卡密账号、已绑定账号。
- 卡密来源微信登录 token 不晚于卡密到期时间。
- 卡密续期后重新登录获得新有效期。
- 微信登录触发全局单点登录，旧 App token 返回 401。

### Admin 解绑

- Admin 可以解绑，业务管理员和普通用户返回 403。
- 重复解绑幂等。
- 解绑只清空新微信身份，不删除卡密、钱包、学习、错题和考试数据。
- 操作日志包含管理员、目标用户、时间和原因，不包含完整 openid。

### 内容安全

以下测试用于 H5 和 Android App 保留的 UGC 流程；微信个人主体提审包不以内容安全代替类目限制。

- 论坛主题使用论坛场景，回复和题目评论使用评论场景。
- 通过后只写入一次。
- 风险和服务异常均不写入业务表。
- 双击提交不会生成重复内容。
- 没有微信 openid 时按当前微信接口允许的请求格式处理。

### 考试草稿

- 两个并发开始请求只产生一个 activeKey。
- 新版本 CAS 成功；旧版本失败；相同版本相同 hash 幂等；相同版本不同 hash 返回 409。
- 延迟 PUT 不能覆盖已提交或已放弃考试。
- 重复交卷返回同一个分数和结果，不重复写错题或练习统计。
- 放弃后可以创建新考试，放弃记录不进入回顾。
- 卡密过期时保留草稿，续期后可恢复。
- M1 32、M2 50、M3 182、M5 70、M9 60 题数和百分制得分正确。

# 机务在线学习平台 — 产品需求文档 (PRD)

## 1. 产品概述
面向航空机务人员的在线培训与学习平台,提供课程学习、考核、钱包充值、订单购课的完整闭环。多租户架构,支持企业/机构独立运营。

**核心目标**:支撑 **2000 人同时在线学习不卡顿**。

## 2. 用户角色
| 角色 | 说明 | 权限 |
|---|---|---|
| 学员(user) | 普通学习用户 | 注册登录、充值、购课、学习、查看进度 |
| 管理员(admin) | 机构管理员 | 发激活码、手动充值、创建课程/章节/课时 |

## 3. 功能需求

### 3.1 账号与认证
- 手机号 + 密码注册(短信验证码),登录返回 JWT
- 验证码:开发模式固定码,生产对接短信服务商
- `GET /auth/me` 获取当前用户身份

### 3.2 钱包
- 余额查询(以"分"为单位存储,前端展示"元")
- 充值码充值(16 位加密随机码,防枚举)
- 微信充值(预单 + 回调入账,金额对账 + 幂等)

### 3.3 课程学习(核心)
- 课程列表(分页)、课程详情(章节/课时树)
- 课时访问控制:free 免费 / paid·vip 需购买 / password 需登录
- 课时播放(视频走 CDN,图文内容)
- 学习进度上报(周期性,断点续学)

### 3.4 订单购课
- 钱包余额购课,生成权益(entitlement)
- 重复购买拦截、余额不足拦截

### 3.5 管理后台
- 批量生成充值码、手动充值
- 创建课程 → 章节 → 课时(三级内容结构)

## 4. 非功能需求

### 4.1 性能(关键)
| 指标 | 目标 | 实测(单进程) |
|---|---|---|
| 同时在线学习 | 2000 人不卡顿 | ✅ 余量 5-27× |
| 课程读 QPS | ≥ 500 | 1904 |
| 进度写 QPS | ≥ 500 | 2737 |
| p99 延迟 | < 100ms | 12-42ms |

### 4.2 安全
- JWT 无状态认证、RBAC 角色鉴权、多租户数据隔离
- 登录限流(防暴力破解)、短信限流(防轰炸)、全局限流(防 DDoS)
- 钱包并发安全(乐观锁防双花)、支付幂等(防重复入账)
- 输入校验(class-validator)、helmet 安全头、CORS 白名单、密钥强校验

### 4.3 可用性与扩展
- 双数据库模式(MySQL 生产 / sqlite 测试)
- 可降级缓存(Redis 多实例共享 / 内存单实例)
- 限流/连接池可配,支持水平扩展

## 5. 关键业务规则
- 金额一律以**分**(整数)存储,杜绝浮点误差
- 钱包扣减:乐观锁 + 事务,并发只成功一次,余额不为负
- 充值码/微信回调:唯一约束 + 幂等,重复请求不重复入账
- 课时权限:后端判定(canOpen),前端仅展示锁状态
- 学习进度:可容忍秒级延迟(写缓冲),非强一致

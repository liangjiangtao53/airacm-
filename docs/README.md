## 最近上线

2026-08-24 的 `v1.1.0.0` 主要更新：

- M1 整包预检支持当前“题库”工作表格式（1.1–7.2 共 23 章、2370 题、51 个标准 Excel 图片引用），并兼容旧版 7 工作表格式；发布仍采用原子切换，不允许从普通导入入口修改。
- Web 与 Android 学习端按章节展示 M1,每章保存独立续学位置;题库发布切换后客户端恢复到新代际的有效章节。
- App 下载页展示微信小程序码,学历提升页客服二维码由后端统一托管并支持资源回退。
- 卡密可标记人工分配状态;生产部署在覆盖镜像前保留回滚标签,并准备 M1 预检文件目录。

历史版本：2026-07-03 上线新的出题规则：

- 顺序学习固定每批 20 题，并从上次学习位置继续。
- 模拟考试按后台科目题量配置出题。
- 模拟考试题源为题库随机题 + 当前用户未掌握错题。
- 题库启动缓存已上线，导入和删除题库时刷新缓存。
- M3 182 题、200 用户并发开始考试，生产实测 200/200 成功，p95 约 1.38 秒。

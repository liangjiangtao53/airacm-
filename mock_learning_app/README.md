# 机务在线学习计费 Mock 第一版

这是基于反编译和动态验证结果做的本地静态原型，用来复原“英语学习 / 课程购买 / 模拟支付 / 权益开通 / 我的学习”闭环。

## 运行方式

直接用浏览器打开：

```text
C:\Users\leifeng\Documents\airacm\mock_learning_app\index.html
```

不需要安装依赖，也不需要启动服务。

## 已实现

- 英语学习首页：参考、练习、课程列表。
- 课程详情：价格、原价、章节/课时、课程来源、购买入口。
- 模拟登录：生成本地 mock token，不连接真实账号。
- 购物车：加入、移除、清空、结算。
- 订单：pending、paid、failed、cancelled 状态。
- 模拟支付：微信、支付宝、钱包三种方式；只改变本地状态，不触发真实扣费。
- 权益开通：模拟支付成功后写入本地 `entitlements`。
- 我的学习：展示已购买课程和课时学习进度。
- 课时访问控制：试听课时可直接学习，付费/VIP 课时需要权益，密码课时需要登录。
- 状态持久化：使用浏览器 `localStorage` 保存登录、购物车、订单、权益和进度。

## 数据来源

- `course-4.html`：学习价 9 元，原价 18 元。
- `course-32.html`：学习价 18 元，原价 36 元。
- 购物车、购买、登录拦截、会员提示来自课程页源码和前面的专项分析。
- APK 原生支付字段参考 `PayInfo`、`PayPopWindow`、`WebObj.pay(...)`。

## 边界

本原型不做：

- 真实账号登录。
- 真实订单号生成。
- 微信、支付宝、钱包、Stripe 真实支付。
- 真实课程权益写入服务端。
- 真实会员套餐读取。

这些需要测试账号和抓包确认后再替换 mock 层。
